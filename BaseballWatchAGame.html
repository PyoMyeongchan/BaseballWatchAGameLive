TOP 2

왜 이 프로젝트인가

  • 본인이 실제로 야구 직관을 다니는 취미가 있어 사용 목적이 명확함
  • 유니티·C# 개발 경험(인터랙티브 병원 시뮬레이션 등)을 살려 새 프레임워크로 확장
  • 완성 시 실사용 + 포트폴리오, 두 마리 토끼를 함께 잡을 수 있음
TOP 3

1단계 핵심 기능

MVP 범위 — 로컬 저장 기준으로 완결되는 4가지 기능

3.1

직관 기록 추가

  • 날짜 · 구장 · 상대팀(홈/원정)
  • 스코어 · 좌석 위치
  • 사진 첨부 (표 · 경기장, 1~2장)
  • 간단한 메모(직관 소감)
3.2

기록 리스트

  • 날짜순 정렬 카드 뷰
  • 대표 사진 · 날짜 · 상대팀
  • 결과(승/패/무) 요약 표시
3.3

기록 상세 보기

  • 사진 크게 보기
  • 전체 메모 · 좌석 · 구장 정보
  • 수정 / 삭제 기능
3.4

통계 대시보드

  • 총 직관 횟수
  • 팀별 직관 승률
  • 구장별 방문 횟수
  • (여유 시) 월별 직관 빈도 그래프

BOT 1

개발 순서

01

Expo 프로젝트 초기 세팅

Claude Code에서 프로젝트 폴더 생성 후 Expo 환경 구성

02

데이터 모델 설계

기록 1건의 구조 정의 — 날짜, 구장, 팀, 스코어, 사진 경로, 메모 등

03

기록 추가 화면

입력 폼 구성 + 로컬 저장 연동

04

리스트 화면

저장된 기록을 불러와 카드 형태로 표시

05

상세 화면

개별 기록 상세 보기, 수정 · 삭제 기능 포함

06

통계 화면

저장 데이터 기반 계산 및 시각화

07

UI 다듬기

아이콘, 색상, 빈 상태(empty state) 화면 정리
